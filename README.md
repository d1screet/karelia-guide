# Карелия: между культурой и тишиной

[Открыть путеводитель](https://d1screet.github.io/karelia-guide/)

Интерактивная карта, два маршрута, десять уникальных мест и фестивальный бонус. Вход и платные ключи не нужны.

`index.html` — автономная версия с встроенными данными, стилями, фотографиями и Leaflet. Подложка OpenStreetMap и веб-шрифты требуют интернета. Авторы и лицензии фотографий доступны в карточках.

`karelia-source.zip` — редактируемые исходники с отдельными файлами данных, фотографий, стилей и логики, инструкцией запуска и журналом проверки.

Публикация через GitHub Pages: ветка main, папка / (root).
