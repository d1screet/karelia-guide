# Карелия: между культурой и тишиной

[Открыть сайт](https://d1screet.github.io/karelia-guide/) — без входа в ChatGPT и GitHub.

Интерактивная карта, два маршрута, десять уникальных мест и фестивальный бонус.

HTML/CSS/JavaScript, локальная Leaflet, реальные лицензированные фотографии. Данные — data.json, авторы и лицензии — assets.json и PHOTO-CREDITS.md. Сборка и платные ключи не нужны.

Для локального запуска: `python3 -m http.server 4173`, затем http://localhost:4173.

Исходники в первоначальной структуре с инструкцией и журналом проверки также доступны в karelia-source.zip. GitHub Pages: main, / (root).
